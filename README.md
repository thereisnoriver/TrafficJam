# TrafficJam — Archived Prototype

> **This project has been consolidated into [TrafficG](https://github.com/thereisnoriver/TrafficG), the actively maintained concert ticketing and waiting-room system.**

TrafficJam began in November 2024 as a traffic-management prototype. Its core ideas around handling user traffic and admission have been carried forward into TrafficG's concert reservation workflow.

This repository is retained for historical reference and its original development history. For the current implementation, architecture, tests, and limitations, see the [TrafficG README](https://github.com/thereisnoriver/TrafficG#readme).
